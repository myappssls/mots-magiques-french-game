# Mots Magiques (الكلمات السحرية)

**Mots Magiques** is a gamified French-learning mobile application designed specifically for Arabic speakers. It turns vocabulary building into an adventure, using dopamine-driven feedback loops and spaced repetition to make learning a habit.

**Mots Magiques** هو تطبيق هاتف محمول لتعلم اللغة الفرنسية بطريقة الألعاب، مصمم خصيصاً للمتحدثين باللغة العربية. يحول بناء المفردات إلى مغامرة، باستخدام حلقات التغذية الراجعة المحفزة للدوبامين والتكرار المتباعد لجعل التعلم عادة.

## Features | المميزات
- **Adventure Map**: Progress through levels from basics to advanced dialogues.
- **Online Integration**: Fetch new words and translations directly from the internet using the MyMemory API.
- **Spaced Repetition (SRS)**: Words you struggle with appear more frequently to ensure mastery.
- **Gamification**: Earn XP, level up, and maintain daily streaks.
- **Time Attack**: Challenge yourself with quick translation tasks.

- **خريطة المغامرة**: تقدم عبر المستويات من الأساسيات إلى الحوارات المتقدمة.
- **تكامل مع الإنترنت**: جلب كلمات وترجمات جديدة مباشرة من الإنترنت باستخدام MyMemory API.
- **التكرار المتباعد (SRS)**: تظهر الكلمات التي تجد صعوبة فيها بشكل متكرر لضمان الإتقان.
- **الألعاب**: اكسب XP، ارتقِ في المستوى، وحافظ على السلاسل اليومية.
- **تحدي الوقت**: تحدَّ نفسك بمهام ترجمة سريعة.

## Technical Stack | التقنيات المستخدمة
- **Language**: Kotlin
- **Architecture**: MVVM (Model-View-ViewModel)
- **Database**: Room (Local Caching)
- **Networking**: Retrofit & OkHttp (Online Translation)
- **UI**: Material Design, ViewBinding
